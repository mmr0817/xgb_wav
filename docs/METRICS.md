## 2. 留出集结果（305 条：bad 46 / good 259）

| 方法 | 阈值来源 | R | P | F1 | 误杀 | AUC |
|---|---|---|---|---|---|---|
| XGB（新威特征） | val 上 max-F1 | 0.9348 | 0.9556 | 0.9451 | 2/259 | 0.9989 |
| wav2vec2 | 固定 0.5 | 0.9565 | 1.0000 | 0.9778 | 0/259 | 0.9985 |
| **融合 + margin 0.2** | val 上「召回≥99.5% 中精度最高」再减 0.2 | **1.0000** | **0.9020** | **0.9485** | **5/259（1.9%）** | **0.9996** |

融合在 margin=0.2 时的表现与「用 test 自身最优阈值（oracle）」完全一致，
说明在当前特征/模型下已达到该召回约束下的最优权衡。

## 4. 生产 checkpoint 的标定方式

生产模型用**全部 2031 条**训练，因此没有独立留出集。阈值通过 **K 折 OOF** 标定：

1. 3 折交叉，每折训练 XGB 与 wav2vec2，得到全量「OOF 概率」；
2. 用 OOF 概率计算各成员的 logit 均值/方差；
3. `threshold = min(OOF bad 的融合分) − margin(0.2)`。

具体数值见 `models/fusion.json` 的 `oof_metrics` 字段。

## 5. 复现

```bash
python scripts/train_production.py --data <raw_dir> --out models \
    --oof-folds 3 --oof-epochs 35 --final-epochs 60 --batch-size 128
python -m xgb_wav.cli --models models --input <wav_dir> --output result.csv
```
